What the editor is and how it is organised, the workspace, and how SVG features map to Lottie.
Read this once; then head to [Quick Start](/docs/svga/editor/quick-start). Which file to save is explained in
[Save, File Format](/docs/svga/editor/save#file-formats-which-one-to-save).

## What Is Pixodesk SVG Animator

**Pixodesk SVG Animator** is a vector drawing and animation editor. You draw shapes, text and
paths on a canvas, animate them with keyframes on a timeline, and save the result as a file that
plays on any web page — as an SVG, as a JSON animation for the Pixodesk player, or as a Lottie
animation.

Pixodesk SVG Animator is also part of **Pixodesk Animator Studio**, the edition that bundles it
with **Pixodesk 2D Animator (Lottie)**. Everything in these docs applies to both; where the Studio edition adds
something, the page says so.

### 1 · Menu bar

The menu bar at the very top gives access to every command, organised into **File**, **Edit**,
**View**, **Object**, **Path**, **Tool**, **Window** and **Help**. Most commands also have a
[keyboard shortcut](/docs/svga/editor/useful-info#keyboard-shortcuts).

### 2 · Toolbar

The horizontal bar directly below the menu bar. Its **left side is context-sensitive** — it shows
the options and actions of the active tool (fill and stroke for a drawing tool, group / align /
arrange for the Selection tool). Its **right side is always the same**: Undo / Redo, Snap, the
Canvas, Zoom and Layout dropdowns, the theme switch, Preview and Export.

Reference: [Toolbar](/docs/svga/editor/canvas#toolbar).

### 3 · Tools panel

The vertical strip of tool buttons on the left. Click a tool or press its key to activate it. The
active tool decides what the Toolbar shows, what the Properties panel shows, and how the mouse
behaves on the canvas.

Reference: [Drawing tools](/docs/svga/editor/canvas#tools-and-toolbar).

### 4 · Canvas

The central working area where you draw, edit and preview. It shows your document at the
current zoom level; rulers along the top and left edges help with placement, and an optional grid
and canvas outline help with alignment. Objects outside the canvas boundary are still part of the
document — hide them with **Clip Canvas Content**. Canvas size and aspect ratio are document
properties; the Page tool changes the size interactively.

References: [Canvas display options](/docs/svga/editor/canvas#rulers-grid-and-background),
[Change canvas size](/docs/svga/editor/canvas#change-canvas-size), [Snap](/docs/svga/editor/canvas#snapping-to-objects-and-grid), [Pan](/docs/svga/editor/canvas#pan), [Zoom](/docs/svga/editor/canvas#zoom).

### 5 · Objects panel

The panel on the far left. It shows everything the document contains, in collapsible sections
that you can resize by dragging their top edge:

- **Object Tree** — the full element hierarchy: select, rename, reorder, show, hide and lock layers.
- **Symbols**, **Markers**, **Patterns**, **Filters** — the reusable definitions stored in the document.
- **Used Colors** — every colour currently in use.

References: [Object Tree](/docs/svga/editor/edit-objects#object-tree), [Symbols](/docs/svga/editor/symbols), [Markers](/docs/svga/editor/markers),
[Patterns](/docs/svga/editor/patterns), [Filters](/docs/svga/editor/filters#shared-filters-and-the-filters-section), [Used Colors](/docs/svga/editor/color#used-colors).

### 6 · Properties panel and sections bar

The panel on the right shows the editable properties of the selected object — or the document
properties when nothing (or the `<svg/>` root) is selected. It is divided into collapsible
sections: Color, Fill, Stroke, Transform, Appearance, Filter, Shape, and more depending on the
object. The narrow **sections bar** on the far right edge toggles each section on or off.

References: [Properties panel](/docs/svga/editor/edit-objects#properties-panel),
[Document properties](/docs/svga/editor/quick-start#document-properties).

### 7 · Timeline panel

The panel along the bottom is where animation happens. From left to right: the **layer list**
with each animated property, the **keyframe editor** with the time ruler and keyframe markers,
and the **chart panel** with the easing curves.

References: [Timeline panel](/docs/svga/editor/animation#timeline-panel), [Keyframes](/docs/svga/editor/keyframes#how-keyframes-work),
[Easing charts](/docs/svga/editor/easing-charts#how-easing-works).

### Preview panel

A floating window that plays the current document with the real player, without saving. Open it
with the **Preview** button on the toolbar. See [Preview panel](/docs/svga/editor/save#preview-panel).

### Status bar

The thin strip at the bottom shows the number of elements in the document and short status
messages.

### Show, hide and resize panels

All panels can be shown, hidden or maximised. Open the **Layout** dropdown on the toolbar (or use
the **View** menu):

- **Maximize Canvas** (`⌘ / Ctrl + F`) — hides all panels to give the canvas the whole window; the same command brings them back.
- **Left Panel** — the Objects panel.
- **Bottom Panel** — the Timeline panel.
- **Right Panel** — the Properties panel and its sections bar.
- **Show Keyframes** — the keyframe editor inside the Timeline panel.
- **Show Charts** — the chart panel inside the Timeline panel.

Drag the edge between two panels to resize them. The four layout buttons in the top bar switch
between preset layouts.

### Dark and light theme

The theme switch on the toolbar's right side toggles between the dark theme (default) and the
light theme. Screenshots in these docs use the dark theme.
