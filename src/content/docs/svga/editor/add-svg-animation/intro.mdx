# Understanding Pixodesk SVG Animations

Pixodesk Animator Studio is a powerful tool for creating advanced SVG animations. Unlike Lottie which exports to a single JSON format, Pixodesk offers **multiple export formats** optimized for different use cases.

---

## Animation Formats

### 1. Animated SVG with CSS Keyframes (.svg)

**Export:** Animated SVG (CSS)

**What is it:**
- A standalone `.svg` file with embedded `<style>` tags
- Uses native CSS `@keyframes` animations
- No JavaScript required to run

**When to use:**
- Simple animations that need to work without JavaScript
- Email templates (where JS is blocked)
- Static sites with minimal dependencies
- Situations where you need a single self-contained file

**Example:**
```astro
<svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
  <style>
    @keyframes fadeIn {
      0% { opacity: 0; }
      100% { opacity: 1; }
    }
    .circle {
      animation: fadeIn 2s ease-in-out infinite;
    }
  </style>
  <circle class="circle" cx="50" cy="50" r="40" fill="blue"/>
</svg>
```

**Usage:**
```html
<!-- Use object tag for external file -->
<object data="animation.svg" type="image/svg+xml"></object>

<!-- Or inline in HTML (paste SVG code directly) -->
<div>
  <svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
    <style>
      @keyframes fadeIn {
        0% { opacity: 0; }
        100% { opacity: 1; }
      }
      .circle {
        animation: fadeIn 2s ease-in-out infinite;
      }
    </style>
    <circle class="circle" cx="50" cy="50" r="40" fill="blue"/>
  </svg>
</div>

```

**Pros:**
- ✅ No JavaScript needed
- ✅ Single file
- ✅ Works everywhere SVG works
- ✅ Lightweight

**Cons:**
- ❌ Limited animation control (can't pause/resume easily)
- ❌ No interactive triggers
- ❌ CSS animation limitations

### 2. Animated SVG with JavaScript (.svg)

**Export:** Animated SVG (JavaScript)

**What is it:**
- A standalone `.svg` file with embedded `<script>` tags
- Uses JavaScript-based animations
- Self-contained with all animation logic included

**When to use:**
- Need more control than CSS keyframes
- Want interactive triggers (click, hover, scroll)
- Need precise timeline control
- Single file deployment preferred

**Example:**
```astro
<svg viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
    <circle id="myCircle" cx="50" cy="50" r="40" fill="blue"/>
    <script>
        const circle = document.getElementById('myCircle');
        let opacity = 0;
    
        function animate() {
            opacity += 0.01;
            if (opacity > 1) opacity = 0;
            circle.setAttribute('opacity', opacity);
            requestAnimationFrame(animate);
        }
        animate();
    </script>
</svg>
```

**Usage:**
```html
<!-- Embed directly -->
<object data="animation.svg" type="image/svg+xml"></object>

<!-- Or inline -->
<div>
  <!-- Paste SVG content here -->
</div>
```

**Pros:**
- ✅ Full animation control
- ✅ Interactive triggers possible
- ✅ Single self-contained file
- ✅ Precise timing control

**Cons:**
- ❌ Requires JavaScript support
- ❌ Larger file size than CSS version
- ❌ Less portable than pure CSS

### 3. Animation JSON with External Player (.json)

**Export:** Animated SVG (JavaScript) → Extract JSON data

**What is it:**
- Separate `.json` file with animation data
- Requires `@pixodesk/svg-animator-web` library to play
- Animation engine runs separately from animation data

**When to use:**
- Building web applications with multiple animations
- Need programmatic control via JavaScript API
- Want to load animations dynamically
- Reusing the same animation in multiple places
- Building animation-heavy applications

**File Structure:**
```json
{
    "type": "svg",
    "viewBox": "0 0 500 500",
    "animator": {
        "duration": 2000,
        "mode": "auto",
        "trigger": {
            "startOn": "click"
        }
    },
    "children": [
        {
            "type": "circle",
            "cx": 250,
            "cy": 250,
            "r": 100,
            "fill": "blue",
            "animate": {
                "opacity": {
                    "keyframes": [
                        { "time": 0, "value": 0 },
                        { "time": 1000, "value": 1 }
                    ]
                }
            }
        }
    ]
}
```

**Usage:**
```javascript
import { createAnimator } from '@pixodesk/svg-animator-web';
import animationData from './animation.json';

const animator = createAnimator(
  animationData,
  null,
  {
    onPlay: () => console.log('Playing'),
    onComplete: () => console.log('Done')
  },
  '#container'
);

// Full programmatic control
animator.play();
animator.pause();
animator.setPlaybackRate(2);
```

**Pros:**
- ✅ Full JavaScript API control
- ✅ Separate animation data from code
- ✅ Load animations dynamically
- ✅ Reusable across projects
- ✅ Best for web applications

**Cons:**
- ❌ Requires external library
- ❌ More complex setup
- ❌ Two files (JSON + library)

## JavaScript Animation Modes

When using `.json` format with `@pixodesk/svg-animator-web`, you can choose different animation engines:

### Mode: "auto" (Recommended)

**What it does:**
- Automatically chooses the best available engine
- Tries `webapi` first, falls back to `frames` if needed

**When to use:**
- Default for most cases
- Let the library decide

**Configuration:**
```json
{
  "animator": {
    "mode": "auto",
    "duration": 2000
  }
}
```

---

### Mode: "webapi" (High Performance)

**What it does:**
- Uses native [Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API)
- Browser-optimized, hardware-accelerated
- Most performant option

**When to use:**
- Modern browsers only
- Need best performance
- Animating transform, opacity, filter properties

**Browser Support:**
- Chrome 36+
- Firefox 48+
- Safari 13.1+
- Edge 79+

**Configuration:**
```json
{
  "animator": {
    "mode": "webapi",
    "duration": 2000
  }
}
```

**Direct Usage:**
```javascript
import { createWebApiAnimator } from '@pixodesk/svg-animator-web';

const animator = createWebApiAnimator(
  animationData,
  {
    onPlay: () => console.log('Using Web Animations API')
  },
  document.getElementById('container'),
  false // Don't force if unsupported properties
);

if (animator) {
  animator.play();
} else {
  console.log('Web API not supported for this animation');
}
```

**Pros:**
- ✅ Hardware accelerated
- ✅ Best performance
- ✅ Native browser support
- ✅ Smooth animations

**Cons:**
- ❌ Limited to Web Animations API supported properties
- ❌ May not support all SVG attributes
- ❌ Older browser compatibility

---

### Mode: "frames" (Maximum Compatibility)

**What it does:**
- Uses `requestAnimationFrame` loop
- Manually updates SVG attributes each frame
- Software-based rendering

**When to use:**
- Need broad browser support
- Animating custom SVG attributes not supported by Web Animations API
- Need guaranteed compatibility
- Targeting older browsers

**Configuration:**
```json
{
  "animator": {
    "mode": "frames",
    "frameRate": 60,
    "duration": 2000
  }
}
```

**Direct Usage:**
```javascript
import { createFrameLoopAnimator } from '@pixodesk/svg-animator-web';

const animator = createFrameLoopAnimator(
  animationData,
  null, // adapter (optional)
  {
    onPlay: () => console.log('Using frame loop')
  },
  document.getElementById('container')
);

animator.play();
```

**Pros:**
- ✅ Maximum compatibility
- ✅ Works in all modern browsers
- ✅ Supports all SVG attributes
- ✅ Precise control over frame rate

**Cons:**
- ❌ Less performant than Web API
- ❌ Not hardware accelerated
- ❌ Higher CPU usage

## Comparison Table

| Feature | CSS (.svg) | JS (.svg) | JSON + Library |
|---------|------------|-----------|----------------|
| **File Type** | Single .svg | Single .svg | .json + JS library |
| **JavaScript Required** | ❌ No | ✅ Yes | ✅ Yes |
| **Programmatic Control** | ❌ Limited | ⚠️ Basic | ✅ Full API |
| **Interactive Triggers** | ❌ No | ✅ Yes | ✅ Yes |
| **File Size** | Smallest | Medium | Largest |
| **Performance** | Excellent | Good | Excellent* |
| **Ease of Use** | Easiest | Easy | Requires setup |
| **Best For** | Static sites | Simple interactivity | Web applications |

*When using `mode: "webapi"`

## Which Format Should You Choose?

### Use CSS SVG (.svg) if:
- ✅ Animation is simple
- ✅ No JavaScript control needed
- ✅ Need to work in email or restricted environments
- ✅ Want smallest file size

### Use JavaScript SVG (.svg) if:
- ✅ Need basic interactivity
- ✅ Want a single self-contained file
- ✅ Don't need complex API control
- ✅ Deploying to simple hosting

### Use JSON + Library if:
- ✅ Building a web application
- ✅ Need full programmatic control
- ✅ Loading multiple animations
- ✅ Need play/pause/seek controls
- ✅ Want to reuse animations
