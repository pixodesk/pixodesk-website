# Getting Started with SVG Animator Web

## Introduction

Bring your Pixodesk-created SVG animations to life on the web with `@pixodesk/svg-animator-web`. This lightweight JavaScript library lets you play advanced SVG animations with interactive triggers, timeline control, and smooth performance.

Unlike Lottie animations which are raster-based, SVG animations created in Pixodesk Animator Studio are true vector animations that scale perfectly at any resolution and support advanced SVG features like masks, clipping paths, and CSS-based animations.

> **Note:** Pixodesk Animator Studio supports **three export formats**: CSS SVG, JavaScript SVG, and JSON. This guide covers the **JSON format with the library**. For other formats, see the [Introduction](/docs/svg-animator-intro).

---

## Quick Start by Format

Choose your preferred format based on your needs:

### Option 1: CSS SVG (No JavaScript)
```html
<!-- Export as "Animated SVG (CSS)" from Pixodesk Animator Studio -->
<!-- Must use object tag or inline SVG - img tag won't animate -->
<object data="animation.svg" type="image/svg+xml"></object>

<!-- Or inline in HTML -->
<!-- Paste your SVG code directly here -->
```
Perfect for email templates and static sites. 

### Option 2: JavaScript SVG (Self-contained)
```html
<!-- Export as "Animated SVG (JavaScript)" from Pixodesk Animator Studio -->
<object data="animation.svg" type="image/svg+xml"></object>
```
Single file with built-in interactivity. 

### Option 3: JSON + Library (Full API Control)
```bash
npm install @pixodesk/svg-animator-web
```
Maximum control with JavaScript API. **Covered in detail in the next section.**


### Basic Usage

After installation, you can import and use the SVG Animator in your JavaScript or TypeScript module:

**index.html**

```html
<!-- Container where the animation will be rendered -->
<div id="animation-container"></div>
```

**index.js**

```javascript
import { createAnimator } from '@pixodesk/svg-animator-web';

// Load animation from URL
const animator = createAnimator(
  '/path/to/your/animation.json',
  null, // adapter (optional)
  {
    onPlay: () => console.log('Animation started'),
    onComplete: () => console.log('Animation complete')
  },
  '#animation-container' // container selector or element
);

// Control the animation
animator.play();
```
