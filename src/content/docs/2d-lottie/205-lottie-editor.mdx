**Pixodesk 2D Animator (Lottie)** is a vector drawing and animation editor that creates and
edits **Lottie** files directly. It is also the Lottie half of **Pixodesk Animator Studio**,
alongside [Pixodesk SVG Animator](/docs) — the two share the same drawing and animation
tools.

## What's here

- **[Add Lottie Animation to Your Project](/docs/2d-lottie/add-lottie-animation-to-your-project)** —
  playing a Lottie file with the Lottie players on the web and in apps: plain HTML, React,
  Vue, Next.js, Nuxt, Astro, iOS, Android, React Native.
- **[Video tutorials](/animator/tutorials)** — drawing and animating, step by step.
- The drawing and animating tools are shared with the SVG Animator editor — the
  [Vector Editing](/docs/svga/editor/canvas) and [Animation Editing](/docs/svga/editor/animation) sections of the
  editor manual apply here too.

## The SVG Animator editor and Lottie

The [SVG Animator editor](/docs) also **imports and exports Lottie**: see
[Export to Lottie, Video, Image](/docs/svga/editor/export) and
[what survives a Lottie export](/docs/svga#svg--lottie-support).
